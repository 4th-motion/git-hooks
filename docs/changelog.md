# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/)
and this project adheres to [Semantic Versioning](http://semver.org/).

## [1.1.1] - 2026-11-14
### Fixed
- `commit-msg` hook no longer rejects messages generated by Git itself:
  - merge commits (`Merge branch …`, `Merge remote-tracking branch …`, `Merge pull request …`), e.g. from `git pull`
  - revert commits (`Revert "…"`) from `git revert`
  - `fixup!`, `squash!` and `amend!` commits from `git commit --fixup/--squash`
- All other messages are still validated against the conventional commit and ClickUp formats, and commits directly to `master` are still blocked.
